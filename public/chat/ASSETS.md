# Bot avatar

`bot-avatar.png` is the unmodified `verity_face_smile.png` texture from
[MrPauk335/Verity-Minecraft-Mod](https://github.com/MrPauk335/Verity-Minecraft-Mod),
retrieved September 10, 2026. The renderer describes these as original textures
from the Bedrock addon. Verity is a character from ThatMob’s Minecraft series.

Source: https://raw.githubusercontent.com/MrPauk335/Verity-Minecraft-Mod/main/src/main/resources/assets/verity/textures/entity/verity_face_smile.png

The asset is copied byte-for-byte; it is not a generated recreation.
