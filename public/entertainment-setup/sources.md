# Browser video

- `enable-cookies.mp4`: native macOS screen recording of Chrome for Testing
  153.0.8010.12, captured September 16, 2026 in a clean browser profile.
- Shows the real Settings → Privacy and security → Third-party cookies →
  site exception flow. The native cursor and click indicators are recorded.
- The video preserves the full browser view without zooming. Only window
  shadows and idle time are trimmed; no browser UI is recreated.
- `enable-cookies-poster.jpg` is the first frame; `enable-cookies.vtt` contains
  English captions. The text below the player also describes the procedure.
- `scripts/prepare-entertainment-demo.mjs` prepares these assets from the
  original native capture. Re-record when the browser controls or domain change.
