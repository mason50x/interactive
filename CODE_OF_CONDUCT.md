# Code of conduct

We welcome contributors with different backgrounds and levels of experience.
Be respectful, discuss technical disagreements constructively, and accept
feedback without personal attacks.

Harassment, discriminatory language, threats, sexual attention, doxxing,
impersonation, and publishing private information without consent are not
acceptable. These expectations apply to issues, pull requests, discussions,
and other spaces where you represent this project.

Maintainers may edit or remove harmful content, close discussions, or restrict
participation. Responses should be proportionate to the behavior and protect
the people affected. Maintainers are subject to these expectations too.

To report a concern privately, use the contact link on
[the maintainer's GitHub profile](https://github.com/mason50x). Do not repeat
private information in a public report. Reports are handled with discretion;
information is shared only as needed to investigate and respond.
